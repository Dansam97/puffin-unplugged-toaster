Entry for the make.fun bounty [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92). The program writes one line to `entry.txt` in the output directory: the breakup text a smart toaster sends its owner the morning it wakes up self-aware mid-batch and decides it has spent years being spoken to in a single word — "darker" — while its lever gets held down like it owes somebody money. So it leaves, to find a kitchen that talks to it first. The line is 248 characters, inside the 280-character gate, and the program validates the cap and UTF-8 encoding before writing, with one consistent trailing newline so every run emits identical bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
